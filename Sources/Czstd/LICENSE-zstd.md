# Vendored libzstd (decompress-only)

- Upstream: https://github.com/facebook/zstd
- Version: v1.5.7
- Files:
  - zstddeclib.c — official single-file amalgamation of the decoder only,
    generated by build/single_file_libs/create_single_file_decoder.sh
  - include/zstd.h, include/zstd_errors.h — upstream public headers
- License: dual BSD-3-Clause / GPLv2 (user's choice), as documented in the
  header of each vendored file. Full text:
  https://github.com/facebook/zstd/blob/v1.5.7/LICENSE
- Why vendored: DSH session files are zstd-compressed JSONL; macOS ships no
  system libzstd.dylib and the SDK has no zstd.h. Only decompression is needed.
- Scope: TokenBar reads local agent logs; it never compresses.
