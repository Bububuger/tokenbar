# TokenBar 1.10.0

This release adds live usage metrics to the menu bar and the popover. Two
distinct metrics ship; they are labeled and unit-tagged separately everywhere
they appear.

**Burn rate (tok/min)** is the default menu bar display. It sums all token
classes — input, output, cache read, and cache write — over a trailing
10-minute window on this Mac and renders as `N/min`. When nothing is
consuming tokens the bar shows `—` instead of a stale value.

**Output speed (tok/s)** measures how fast a completed response produced
output tokens, wall-clock dispatch to response end, time-to-first-token
included. Only final responses with source-recorded start/end bounds count;
streaming estimates and adjacent-event gaps are never used. Select it from
the menu bar mirror picker; the bar renders `N tok/s` or `—` when the
current sources report no timing. Timing extraction ships for Codex,
Claude Code, Gemini CLI, OpenCode, Grok CLI, oh-my-pi, and DeepSeek Harness.
Sources without usable timing continue to report usage as before and show
`—` in this mode.

A new **Rate** tab in the popover's Rankings section breaks the same two
metrics down per agent, and per agent×model where model attribution exists.
Rows follow the active mirror mode's metric and unit, so the drilldown never
mixes tok/min with tok/s under one label.

Remote Cursor dashboard events remain excluded from both metrics: they
describe account-scope activity, not this Mac's. The release is a single
menu bar item throughout; no additional status bar entry was added.
