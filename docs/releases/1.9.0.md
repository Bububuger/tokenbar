# TokenBar 1.9.0

This release adds local usage support for four agents:

- Grok CLI: turn usage, cache reads and writes, reasoning, and source-reported cost.
- Devin CLI: ATIF transcripts, session project attribution, and cache accounting.
- oh-my-pi (OMP): session history, reasoning, and source-reported cost.
- DeepSeek Harness (DSH): legacy and v4 compressed session logs, including incremental refresh.

TokenBar now registers 17 built-in sources from one shared catalog used by the
app, settings, diagnostics, and CLI.

Cost summaries preserve reported amounts, including zero. When an event has no
reported amount, TokenBar uses the existing agent defaults; CLI `costSource`
identifies `actual`, `defaults`, or `mixed`. Reported amounts describe the local
agent ledger and are not an external billing reconciliation. Devin subscription
spend remains unavailable.

Fixes include mixed-cost totals in Details, Devin cache-write classification,
DSH empty/skippable compressed frames, native Xcode integration of zstd, and CLI
dispatch when `--db` precedes the command.

OMP error and aborted turns continue to be excluded under the existing parsing
policy. The unfinished Antigravity SQLite prototype is outside this release.

The local candidate contains both TokenBar.app and its embedded tbar CLI. It uses
the existing ad-hoc signing workflow. The public update manifest stays on 1.8.12
until the 1.9.0 tag and matching DMG are published.
